# 꼬물꼬물 지렁이

사과를 먹으며 지렁이를 키우는 브라우저 게임입니다. 벽이나 자신의 몸에 닿으면 게임이 끝나며, 사과 하나를 먹을 때마다 10점을 얻습니다.

## 실행 방법

1. 저장소의 Code → Download ZIP을 선택해 내려받습니다.
2. 압축을 풀고 `index.html`을 브라우저로 엽니다.
3. 게임 시작 버튼을 누릅니다.

`index.html`과 `game.js`를 같은 폴더에 두세요. 별도 설치나 빌드가 필요하지 않습니다.

## 조작 방법

- 컴퓨터: 방향키 또는 W/A/S/D로 이동합니다.
- 모바일: 화면의 방향 버튼이나 게임판 스와이프로 이동합니다.
- 일시정지 및 계속하기: 스페이스 키 또는 일시정지 버튼을 누릅니다.
- 속도: 세 단계 중 선택하며 다음 게임부터 적용됩니다.

최고 기록은 현재 브라우저의 로컬 저장소에 저장됩니다.

## 파일 구성

- `index.html`: 게임 화면과 CSS
- `game.js`: 게임 동작과 점수 처리
- `README.md`: 프로젝트 설명과 실행 방법
- `.gitignore`: 임시 파일 등 업로드 제외 규칙

HTML, CSS, JavaScript로 제작되었으며 외부 API나 로그인은 사용하지 않습니다.

## 실행 확인 상태

게시된 프로젝트의 원본 파일을 가져와 제출용으로 정리했습니다. 이 사본의 브라우저 실행은 아직 미확인입니다.
